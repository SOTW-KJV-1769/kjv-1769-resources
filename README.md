# Servants of the Way Digital Library | King James Version (1769)

A standalone, text-only Scripture translation foundation built from the owner-vetted public-domain eBible **`eng-kjv2006`** USFM archive. This source represents the King James Version's standardized **1769** text, not a facsimile of the first **1611** printing.

**Coverage:** 66 books · 1,189 chapters · 31,102 verses. All chapter data use shared reference IDs such as `GEN.1.1` and edition IDs such as `KJV1769:GEN.1.1`, retaining ASV book slugs and catalog structure.

- `index.html`: book selection.
- `books/<slug>/site/index.html`: individual book/chapter/verse reader.
- `data/kjv1769/<slug>/chapters/NN.json`: Scripture text with italicized supplied spans.
- `data/kjv1769/catalog-<slug>.json`: per-book metadata.
- `data/kjv1769/route-map.json`: logical future links to external original-language and commentary resources.
- `docs/EDITION.json`: source/rights/credit metadata shared across all books.
- `docs/SOURCE_LOCK.json`: archive and per-file SHA-256 verification.
- `docs/QA_REPORT.md`: exact checks, limitations.
- `docs/UPLOAD_GUIDE.md`: manual GitHub-root installation.

**Presented by the Servants of the Way Digital Library.** Source edition record: https://ebible.org/Scriptures/details.php?id=eng-kjv2006. Public-domain Scripture text outside the United Kingdom, subject to UK Crown printing-rights restrictions described by the source.

No scanned page PDFs, Strong’s numbers, original-language conclusions, or historical-commentary text are published as part of the KJV chapter records. These other resources remain separately governed and will be connected by a future UI. This release does not change the ASV repository or CGBC player.
