# Stable references and existing SOTW foundations

The unqualified reference `GEN.1.1` is a shared Scripture identity, **not** a text or alignment claim. KJV text is stored as `KJV1769:GEN.1.1` and uses the ASV-style verse record keys `id`, `edition_verse_id`, `verse`, `spans`, and `paragraph_start`. All 66 ASV book slugs and canonical book codes were reused without altering ASV.

The original-language sites already contain chapter-level `verses["GEN.1.1"].KJV1769` word-link evidence. The native tagged-USFM word ordinals are **not** English display token offsets. Verse-click expansion must use those separate approved datasets and their versioned contracts later; this release contains no lexical or Strong’s payload and makes no fabricated token-position claims.

The historical-commentary library has separately anchored commentary keyed by shared Scripture IDs; its own versioning, rights, and coverage govern any future connection. No commentary is copied, nor is an API/reader implementation claimed.

This is an independent translation data release. It does not modify the existing ASV, original-language, historical-commentary, or CGBC player repositories.
